# backend-api-w1

นราธิป ภูเพ่น 69319010020

## โครงสร้าง

- `docs/uml/` — เอกสารและแผนภาพ UML
- `src/routes/` — กำหนดเส้นทาง API
- `src/controllers/` — จัดการคำขอและการตอบกลับ
- `src/models/` — โมเดลและการเข้าถึงข้อมูล
- `src/config/` — การตั้งค่าแอปพลิเคชัน

## เริ่มต้นใช้งาน

1. คัดลอก `.env.example` เป็น `.env` แล้วปรับค่าตามสภาพแวดล้อม
2. ติดตั้ง dependencies ที่โปรเจกต์ต้องใช้
3. รัน `npm start` เมื่อเพิ่ม entry point ที่ `src/index.js` แล้ว
